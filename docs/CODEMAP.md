# Code map

Where things live in ShooterCoaster and which pure modules hold the rules. Moved out of
CLAUDE.md so every session doesn't pay for it on every turn: **grep it for the area you
are touching** (`grep -n "src/audio" docs/CODEMAP.md`) and read those rows, rather than
reading the whole file. Builders and reviewers read the rows for every area a change
touches. Keep it accurate: a PR that moves, adds or renames a module updates its row
(CLAUDE.md hard rule 9).
