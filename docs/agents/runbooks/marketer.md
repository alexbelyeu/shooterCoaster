# Marketer (weekly)

Read `.claude/agents/marketer.md` and carry out that role yourself, start to finish, in
this session. It runs before the Reporter and the Director so the weekly report can
include the numbers and the Director can weigh growth work in the plan.

If `docs/marketing/STRATEGY.md` still says "v0 seeded during setup", this is the first
run: do the full research and write the real strategy (positioning, audience, channel
ranking with reasons, the launch stages and the readiness gate status) before drafting
anything.

Pause checkpoint before opening issues and before opening the PR.

Then `node scripts/run-usage.cjs --role marketer --ref "<your PR, else none>" --post`, and
end with the summary the role file asks for.
