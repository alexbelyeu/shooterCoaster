## 2026-11-21 — Total JS budget 630 → 636 KB (Director, #793 / #796)

**Context:** `jsTotalGzipKB` was lowered 700 → 630 when Tone.js left, to lock in the saving. Since then the game has grown into it: `main` after #804 measures 644 662 B (629.55 KB), 458 B of headroom. Ocean's whale breach (#796) costs 1 273 B after the builder already cut it from 1 872 B; it is over by 815 B, and so would be any PR adding ~0.5 KB of game code. The whale lives in level 3's lazy chunk, so it costs a player nothing at startup.
**Decision:** Raise `jsTotalGzipKB` to 636 (651 264 B): the whale fits with ~4.9 KB left for this week's queue (#329's title flow, #803's level-data field). The two budgets that a first-time player actually pays for stay where they are: `startupJsGzipKB` 435 and `jsLargestChunkGzipKB` 260. This is not a standing allowance: the next PR that hits 636 cuts code elsewhere (or proposes a cut) in the same request before asking for another raise.
**Consequences:** Total JS may grow ~1 % more. Lazy level chunks are where the growth is expected (one per world); the startup budget is still the gate on load time.
